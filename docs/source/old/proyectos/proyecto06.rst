=============================
Proyecto 06: Backend - Django
=============================

.. topic:: Objetivo general
    :class: objetivo

    Desarrollar una aplicación de backend utilizando Django que actúe como intermediario seguro y eficiente para la gestión de datos facilitando operaciones de lectura, escritura, actualización y eliminación mediante endpoints estructurados y promoviendo el uso de buenas prácticas de desarrollo backend, autenticación, y comunicación entre servicios distribuidos en aplicaciones modernas.
