==============================================
Proyecto 03: Dashboard interactivo
==============================================

.. topic:: Objetivo general
    :class: objetivo

    Desarrollar un dashboard interactivo y visualmente intuitivo utilizando tecnologías web modernas, como React y TypeScript, que permita a los usuarios monitorear en tiempo real métricas, fomentando la exploración de buenas prácticas de programación y el uso de herramientas actuales en el desarrollo de interfaces dinámicas.
